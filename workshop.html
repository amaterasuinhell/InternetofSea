Swimmer workshop

Edit the code on the left and the swimmer redraws on the right. A swimmer is a picture drawn with a few lines of code on a 128×128 canvas, in two frames that the sea swaps to make it swim.

Turn on the grid and move over a frame to read its x, y position (0 to 128).

What you can use in the code

  • c is the drawing pen. c.beginPath() starts a shape, then add c.ellipse(x, y, radiusX, radiusY, 0, 0, 7), c.arc(x, y, radius, 0, 7), or c.moveTo(x, y) and c.lineTo(x, y) for straight edges.
  • fill() paints the current shape in the swimmer’s color, using the chosen style (outline, shadow, and so on).
  • line([[x1,y1],[x2,y2],…], outlineWidth, colorWidth) draws a thick line, good for tails, legs and fins.
  • legs([[startX,startY,endX,endY,curl], …]) draws wavy tentacles that curl one way in frame 1 and the other way in frame 2.
  • eye(x, y) draws an eye.
  • f is 0 or 1, the frame number. Use it to move something: const up = f ? -8 : 8;
  • col is the color. Draw what sits behind first, because later shapes cover earlier ones.

Put it in the sea

  • Button 1: in index.html, find critterTex and paste the text on its own line just above the final }else{ (the fish). Then add the VARS entry it shows. Make sure the line helper from the style block exists there too.
  • Button 2 changes how every swimmer is drawn. Replace the existing const fill, legs, eye (and line) helpers in critterTex with it. The pixel style also needs a smaller canvas, explained in the text it gives you.
  • If your swimmer faces left, like the fish, also add its name to the fish= and sz lines so it flips and keeps a steady speed.
